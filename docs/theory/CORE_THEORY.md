# Chemistry Framework · 理论主线（公开版）

本文件只列出可公开讨论的化学理论连接，不包含任何私人科研项目、实验配方、未公开数据或专属研究假说。各关系是学习索引，不代表全部体系共享相同机制。

## 1. 电子结构 → 化学结构

在给定哈密顿量、核构型、边界条件与近似方法下，可求解电子态及相关性质。绝热近似与局域基组的适用性必须说明；轨道示意不等于真实电子密度计算。

## 2. 微观状态 → 热力学

若体系处于指定统计系综且模型给定能谱/态密度，则可构造配分函数。正则系综中：

$$
Z=\sum_i e^{-\beta E_i},\qquad F=-k_BT\ln Z.
$$

实际溶液、界面与开放体系需要额外描述环境、组分和约束；不能由单一分子总能直接推出真实反应自由能。

## 3. 化学势 → 反应平衡与动力学

在适当条件下，反应吉布斯自由能和反应商满足：

$$
\Delta_rG=\Delta_rG^\circ+RT\ln Q.
$$

动力学还需单独给出速率模型、路径、势垒及传质条件。热力学平衡、动力学稳态与局部能量极小不能混同。

## 4. 电化学 → 真实装置响应

电化学体系涉及电极反应、电解液电势、电化学势、界面动力学和物质传输。开路电动势、工作端电压与反应速率不是相同变量。真实电池还受温度、负载、活度、极化、副反应和老化影响。

## 5. 从模型走向验证

任何预测都需指定状态变量、实验观测量、可比条件、假设与证据来源。模型拟合并不自动证明唯一反应机理。详见 [科学内容规范](../SCIENCE_POLICY.md)。
