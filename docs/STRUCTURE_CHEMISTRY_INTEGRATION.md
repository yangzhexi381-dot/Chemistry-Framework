## 物理说明

1. 无限深势阱为解析玩具模型；量子态的离散性来自边界条件，不等同于原子势的轨道图像。
2. 类氢轨道概率点云需要区分波函数相位、体积概率密度和径向概率密度。
3. LS 耦合假定该耦合方案适用，p² 受等价电子的反对称性限制。
4. 正交双态的 H 是普通本征问题；H₂⁺ 非正交 LCAO 则须使用广义本征方程 `Hc=ESc`。不得将双态示意当作 H₂⁺ 的精确求解。
5. 谐振子与 Morse 势曲线采用无量纲参数；IR、Raman 与 Franck–Condon 中示意的谱峰强度并不是特定分子的预测谱。
6. C₂ᵥ 的轴与分子平面约定为 z、xz；对称允许不意味着矩阵元绝对非零。
7. Hückel 的开链公式建立在正交局域 p 轨道、最近邻耦合的假设下。

## Morse 束缚态与双态本征矢

- Morse 模型令 ℏω=1，以 ℏω 为能量单位，并取平衡点附近的无量纲曲率为 1。整数 v≥0 须满足 v+½ < 2Dₑ 才是束缚态。能量多项式越过这个区间后会回落，因此不能单用 Eᵥ < Dₑ 判断束缚。纯模型检查量子数并求解 V(q)=Eᵥ 的两个经典转折点，绘图只呈现有效能级。Dₑ=3 时，v=5 的能量为 143/48，v=6 越界。这些转折点对应经典允许区间的边界，振动态的波函数仍可延伸到该区间外。
- 正交双态 Hamiltonian 的对角元为 ±Δ/2，非对角元为 V，Δ 和 V 在界面以 eV 输入。非零 V 下按矩阵残差核验最低能态，避免固定阈值把微弱但非零的耦合当成零。Δ=V=0 时两态简并，接口返回一个归一化基态代表。系数的整体符号取决于相位约定。
