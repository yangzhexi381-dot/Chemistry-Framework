## 物理说明

1. 无限深势阱为解析玩具模型；量子态的离散性来自边界条件，不等同于原子势的轨道图像。
2. 类氢轨道概率点云需要区分波函数相位、体积概率密度和径向概率密度。
3. LS 耦合假定该耦合方案适用，p² 受等价电子的反对称性限制。
4. 正交双态的 H 是普通本征问题；H₂⁺ 非正交 LCAO 则须使用广义本征方程 `Hc=ESc`。不得将双态示意当作 H₂⁺ 的精确求解。
5. 谐振子与 Morse 势曲线采用无量纲参数；IR、Raman 与 Franck–Condon 中示意的谱峰强度并不是特定分子的预测谱。
6. C₂ᵥ 的轴与分子平面约定为 z、xz；对称允许不意味着矩阵元绝对非零。
7. Hückel 的开链公式建立在正交局域 p 轨道、最近邻耦合的假设下。
