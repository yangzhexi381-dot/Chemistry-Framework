SYSTEM FIRST · TEXTBOOK CROSSWALK

从一只铅酸蓄电池，贯通电化学

先看真实器件如何工作，再把同一套过程映射到教材第八至第十章。

通用教学案例 · 不含个人课题
系统边界负极 Pb / PbSO₄H₂SO₄ 水溶液与隔板正极 PbO₂ / PbSO₄

示意为铅酸蓄电池单体。器件结构与实际工况会更复杂；本页用于串联基本原理，不是性能预测软件。

切换工作状态
电子：负极 Pb → 外电路 → 正极 PbO₂化学能 → 电能 → 外部负载
负极Pb + SO₄²⁻ → PbSO₄ + 2e⁻氧化 · 电子进入外电路
电解液H₂SO₄(aq)离子传导 · 活度随状态改变
H⁺　HSO₄⁻　SO₄²⁻
正极PbO₂ + 4H⁺ + SO₄²⁻ + 2e⁻ → PbSO₄ + 2H₂O还原 · 电子由外电路到达
总反应：Pb + PbO₂ + 2H₂SO₄ → 2PbSO₄ + 2H₂O

放电时，氧化还原反应推动电子经外电路由负极流向正极；电解液内由离子承担电荷传递。

放电反应进度模型

拖动归一化反应进度 ξ/ξₘₐₓ；假设初始活性物质按总反应计量配比、无副反应。柱形表示理论反应份额，不代表真实电量或浓度。

归一化量仅显示化学计量关系；实际容量还受活性物质量、利用率、副反应、倍率、温度与截止条件影响。

同一个器件，四条线同时发生

物质变化

两极活性物质转为 PbSO₄，硫酸和水的组成随反应进度变化。

电荷传递

电子走外电路，离子在电解液中迁移；两者共同闭合电流回路。

热力学驱动

反应 Gibbs 能变化决定可逆电动势；活度进入 Nernst 方程。

实际响应

电阻、界面动力学与传质形成压降和极化，使带载端电压偏离可逆值。

TEXTBOOK CROSSWALK

再按教材顺序拆解

章节结构依据傅献彩、侯文华《物理化学》（第六版）下册第八至第十章目录；下列内容为教学重述。

第八章 电解质溶液 描述电池内部的离子与电解液

8.1 电化学基本概念与电解定律

区分原电池与电解池，建立电量、电子计量与物质量之间的关系。

Q = ∫I dt；n = Q/(zF)

8.2 离子的电迁移率和迁移数

电场驱动离子迁移；迁移数表示某类离子承担的电流份额。总和为 1。

tᵢ = Iᵢ/I；Σtᵢ = 1

8.3 电解质溶液的电导

从电导、电导率、摩尔电导率出发，讨论浓度效应、离子独立移动定律及电导测量的应用。

G = 1/R；κ = G·l/A；Λₘ = κ/c

8.4 平均活度与离子强度

单个离子的活度不能独立热力学测定；电解质溶液通常使用平均离子活度因子。离子强度衡量离子组成对非理想性的影响。

I = 1/2 Σ mᵢzᵢ²

8.5 强电解质溶液理论简介

Debye–Hückel 离子互吸理论解释稀溶液中活度偏离；Debye–Hückel–Onsager 理论进一步讨论电导。它们有明确的稀溶液适用边界。

log₁₀γᵢ ≈ −A zᵢ²√I（极限稀溶液）
第九章 可逆电池的电动势及其应用 把电池反应连到化学热力学与测量

9.1 可逆电池和可逆电极

明确电池反应、半电池反应、电极类型与可逆条件；铅酸电池反应可作为贯穿示例。

9.2 电动势的测定

理解对消法为何能在近似零电流下测量电动势，并认识标准电池的作用。

9.3 电池书写与电动势取号

先固定电池书写约定和反应方向，再判断符号，避免把电极电势与电池电动势混为一谈。

E_cell = E_right − E_left（按约定书写）

9.4 可逆电池热力学

由电动势得到反应 Gibbs 能；温度系数提供反应熵、焓信息；标准电动势可用于平衡常数。

ΔᵣG = −nFE；ln K = nFE°/(RT)

9.5 电动势产生机理

逐步区分电极/溶液界面电势差、接触电势、液体接界电势与整体电池电动势。

9.6 电极电势与电池电动势

以标准氢电极建立相对电极电势标尺，再依据电池反应计算电动势。

9.7 电动势测定的应用

将可逆电势测量用于平均活度因子、难溶盐活度积、pH、电势–pH图、膜电势、离子选择性电极与传感器。

拓展：内电位、外电位与电化学势

电化学势把化学势与带电粒子所处电势联系起来，是理解界面和电池驱动的重要桥梁。

μ̃ᵢ = μᵢ + zᵢFφ
第十章 电解与极化作用 解释真实电池为何偏离可逆极限

10.1 分解电压

比较热力学分解电压与实际启动电解所需电压，指出电极过程和欧姆损耗的影响。

10.2 极化作用

分开浓差极化与电化学极化；通过极化曲线和超电势表征实际偏离，并理解氢超电势及 Tafel 关系的适用区间。

η = E_actual − E_equilibrium；η = a + b log|j|（特定动力学区间）

10.3 电解时电极上的竞争反应

析出、析氢和其他电极过程可能竞争；产物分布取决于电极电势、动力学、传质和反应物活度。

10.4 金属腐蚀、防腐与钝化

把局部阳极/阴极过程用于解释腐蚀，将保护方法与电极反应及界面状态对应起来。

10.5 化学电源

以燃料电池和蓄电池为例，比较电能与化学能的转换方向，以及可逆性、效率和实际损失。

拓展：电有机合成

把电极反应作为可调控的氧化还原条件，关注电势、选择性和传质之间的联系。

模型边界
